# 🚀 Mirikano's Blog

個人ブログのソースコードリポジトリです。[GitHub Pages](https://pages.github.com/) と GitHub Actions を利用して自動デプロイしています。

🔗 **公開サイト:** [https://mirikano.github.io/Mirikano_BLOG/](https://mirikano.github.io/Mirikano_BLOG/)

---

## 🛠 Tech Stack (使用技術)

* **静的サイトジェネレーター:** [Hugo](https://gohugo.io/) (Extended)
* **テーマ:** [Hugo PaperMod](https://github.com/adityatelange/hugo-PaperMod)
* **ホスティング & CI/CD:** GitHub Pages & GitHub Actions
